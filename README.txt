BUMI BERSAMA — WEBSITE PEDULI ALAM

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder bumi_bersama_website.
3. Klik dua kali index.html, atau buka folder melalui VS Code lalu gunakan Live Server.

Isi:
- index.html: struktur dan konten website berbahasa Indonesia
- style.css: desain responsif dan palet warna
- script.js: menu mobile, formulir relawan demo, dan animasi saat scroll

Catatan:
- Foto memakai URL gambar Unsplash, sehingga koneksi internet diperlukan agar foto tampil.
- Formulir relawan saat ini hanya simulasi antarmuka di browser dan belum menyimpan/mengirim data.
- Untuk penggunaan nyata, formulir perlu dihubungkan ke backend/database dan informasi program perlu disesuaikan dengan organisasi yang benar-benar menjalankannya.
